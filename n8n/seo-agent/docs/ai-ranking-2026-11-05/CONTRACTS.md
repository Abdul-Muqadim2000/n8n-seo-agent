## 3. Kits

Input shapes P4 builds for `diagnose`: `index = { google: Map(url_key -> state), bing: { in_account: bool | null, crawled: Map(url_key -> iso) },
brave: Map(query -> [{ url, pos }]) | null, cc_captures: number | null }`; `serp = Map(normalised query -> { results: [{ url, pos }], read_at,
location_code })` from `seo_cache` `serp:*` rows (`SC.parse`, any date, labelled with `read_at`); `access = { robots: { [bot]: { allowed_root,
rule } }, blocked_engines: [engine], read_at }` from this run's `Robots Verdicts (Growth)`; `pages` = `seo_ai_pages` rows of the site;
`stage` / `sub` / `basis` vocabularies are DESIGN 2.B's (`blocked`, `js_only`, `not_indexed`, `not_asked`, `too_few`, `weak`,
`low_position`, `negative`, `wrong`; basis `direct` | `proxy_rank` | `unknown_index`). `names_client` is `null` when the page answered 403.
Every function ignores `gemini_api` rows (`AIRF.usable`).

### 3.3 ARL (P2 fills; signatures and shapes frozen; AIRW0-3 holds them)

```js
ARL.LEVERS        // L01..L17: { id, label, from: [stage], to, next: { from: to }, sub: [], mult: { engine | '*': n }, prior: { mean, n0 } | null,
                  //   gate?, days: [min, typ, max] | null, usd, effort_min, executor: auto | approve | human, scope: question | page | site,
                  //   sink, sink_wave2, evidence: [] }       sinks: ai_target | prospect | listing | growth_action | site_task | protect | existing
ARL.REFUSED       // six: { id, label, why, evidence }      ARL.ZERO_WEIGHT ['schema', 'llms_txt']
ARL.U             // { S0: 0, S1: 0.03, S2: 0.15, S3: 0.25, S4: 0.45, S5: 0.8 }
ARL.VERDICTS      // ['likely_helped', 'cant_tell', 'no_effect', 'not_happened', 'not_due']
ARL.MEMO_PARTS    // ['what_changed', 'why', 'detectable', 'actions', 'projected_vs_real', 'cost_per_win', 'shadow_vs_old'] + MEMO_TITLES
ARL.value({ prompt, demand, intent, stage })          -> { V, demand_w, intent_w, stage_w, basis }
ARL.feasibility({ prompt, market, diag, reach })      -> { F, market_w, comp_w, reach_w, basis }
ARL.priorOf({ lever, stage, group, priors, site_id }) -> { a, b, mean, lo90, hi90, n, source: 'evidence' | 'pooled' | 'site' }
ARL.candidates({ site, diag, sources, arms, stored_actions, settings, now }) -> [candidate]
ARL.score(candidate, { priors, values, feas, weights, H }) -> { gain, cost, score, p_by_cell: [], days, why }
ARL.choose(scored, { capacities, arms, mode, open_actions }) -> { chosen: [action], deferred: [{ action, why }], refused: [{ what, why }] }
ARL.prereg(action, { arms, units60, now }) -> { metric, questions, engines, controls, window_days, t0_rule: 'live_at' | 'happened_at', projected: { p, gain }, registered_at }
ARL.verify(action, { contentLog, pages, index, listings, outreach, sources, robots, bing, now }) -> { happened: true | false | null, at, evidence }
ARL.outcome(action, { units60, diagNow, diagAtT0, arms, now }) -> { due, stage_moves: { k, n, b }, did, placebo,
                                                first_appearance: { t: { k, n }, c: { k, n }, p_fisher, p_binom }, leading, verdict, why }
ARL.learn({ priors, outcomes, now }) -> [prior rows to upsert]          (new or changed only; [] = nothing learned)
ARL.memo({ site, diagNow, diagPrev, chosen, open, outcomes, mde, blockers, cost, old, mode })
  -> { v: 1, rule_version, site_id, mode, parts: [{ key, title, lines: [{ text, figures: [{ name, value, basis }] }] }] (the seven, in order), blockers: [] }
ARL.compareOld({ chosen, old: { targets, earned, actions } }) -> { overlap, gain_air, gain_old, causes: { air: [], old: [] }, note }
```

`action` (also the source of a `seo_ai_rank_actions` row): `{ action_id: AIRF.actionId(site_id, lever, ref), site_id, lever, executor,

## 4. Wiring (AI Growth workflow, `SEOagentAIGrow1`)

`build_monitors.py` (W0) makes `AI Growth Row -> Any Growth Row?` and `Any Growth Row? (true) -> Save AI Growth`, then calls:

```python
ai_rank_wiring.wire(G, 'Any Growth Row?', 'Save AI Growth', 'Growth Report', at(60, 3))      # P4 fills; W0: the two old links

```

P4's graph (node names frozen; every AIR node `onError: continueRegularOutput`; IFs on `{{ !$json.skip && !$json.error }}`):

```
Any Growth Row? (false) ─┐
Save AI Growth ──────────┴─> AI Rank Gate -> Any AI Rank? --false--> Growth Report
                                                \--true--> Ensure AI Rank {Runs,Questions,Actions,Sources,Priors} Table
   -> Load AI Rank Questions -> Load AI Rank Actions -> Load AI Rank Sources -> Load AI Rank Priors -> Load AI Rank Runs (84 days)
   -> Load Index Pages (Rank) -> Load SERP Cache (Rank) (kind serp) -> Load AI Daily (Rank) (60 days) -> Load Listings (Rank)
   -> Load Link Outreach (Rank) -> Load Link Prospects (Rank) -> [wire_requests: AI Rank Requests ... AI Rank Fetched] -> AI Rank Plan
   -> AI Rank Run Row / Question Rows / Action Rows / Source Rows / Prior Rows  (shadow + on)
   -> AI Rank Target Rows / Prospect Rows / Prompt Rows (Save AI Rank Proposed, Set Core Until) / Cache Rows / Growth Patch  (on only)
   -> saves -> Growth Report   (exactly once per run)
```

`AI Rank Gate` (inlines `_monitor_sites.js` + AIRF; reads `air:kill` from a `seo_cache` load) outputs one item per site with
`AIRF.runs(...)` true: `{ site_id, domain, mode, rank, run_id }`, or `[{ skip: true }]`. It must not change any upstream node's output.
**With every site off, only `AI Rank Gate` and `Any AI Rank?` may execute (AIRG2).**

`AI Rank Plan` output, one item per site: `{ site_id, domain, mode, run_id, air: { market, panel: { core, proposed, extend, comparable, why,
arms, mde }, diag: [diagnose], sources: [source], candidates, chosen, deferred, refused, outcomes, priors, memo, compare, cost: { usd,
basis } }, error: '' }`. It reads the old logic's choice from `$('Growth Plan')`, `$('Earned Media')`, `$('Growth Metrics')` explicitly
(never `$json` after a Data Table node), ladder keywords through `FITR.fitStored`, and `$('AI Rank Fetched')` inside try/catch.

P4 adds `settings.rank = AIRF.settingsOf(m)` in `_monitor_sites.js` and must check that no callback or report copies `settings` wholesale
(if one does, `rank` is stripped there, so callbacks keep their shape). P3 reads `s.settings.rank && s.settings.rank.mode` (undefined = off).
