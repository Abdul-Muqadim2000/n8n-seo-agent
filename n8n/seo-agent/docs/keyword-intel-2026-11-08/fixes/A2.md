## Deviations and open items
1. **`hidden` stays on the two modes.** The tools page, tool form, sidebar and pages gate on the website's KI visibility instead; the runs
   filter and the API / MCP `list_modes` keep leaving them out. `list_modes` has no website argument, so listing them would show every
   API client (Off sites included) something new; exposing them per website is a server change (A1 / W2 decision). `start_run` already
   refuses Off sites (W0 guard).
2. **Plan source.** No A1 route carries the plan; the page reads `plan` from the overview or the keywords answer when present, else the
   latest `ki_research` report payload (one extra request, only for the plan panel). Suggest A1 / W2 adds `plan` to `GET .../ki`.
3. **Start buttons** stay "Coming soon" until the overview sends `plan_start: true` (A1 answers 501 and does not send it), so no click
   ever hits the 501. Gap Start uses the plan route with the gap id (to confirm with W2).
4. **Gap-type filter** on keywords is applied to the rows shown (A1 ignores `gap_type`); a server filter would make the count exact.
5. **Hero counts** come from A1's `summary`, then the run's counts, then the rows on screen.
6. **KI nav not in the client portal** (A1 answers 403 to client roles; pages not in `PORTAL_SITE_PAGES`).
7. One wip commit (5b5a1562) precedes the merge of `ki/a1`; the final commit holds everything after it.
