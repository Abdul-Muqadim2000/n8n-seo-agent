## Deviations from the contract, and why
1. **No ledger / rate limit / budget in the skeleton.** It refuses before any spend and writes nothing, so it reserves nothing (like a
   `free_only` run). Build section 55's proof only walks the workflows in `ledger_wiring.json`; E2 adds the worker's reserve / settle there.
2. **`market` is '' in the refusal.** The COUNTRIES lookup and the `market_mismatch` refusal are E2's Normalize.
3. **Site delete does not remove KI rows yet** (section 5): no KI rows exist before E2, and the delete belongs with E2's Site Admin KI actions.
4. **`hidden` flag on `ModeInfo`** (not in the contract): needed so adding the modes to `MODE_IDS` exposes no UI; A2 removes it.
5. **The app guard reads `ki_mode` only**, not the kill switch: the engine owns the kill switch and its refusal ends the run uncharged.
6. Existing checks that listed every mode or column by hand were extended, not weakened: AIRW0-4 (AIR block position, KI after it),
   AIRW0-5 / FXB6 (new null monitor columns allowed like AIR's), S44 (allow-list 17 -> 18), `payload.test.ts` / `report-delivery.test.ts`.
7. Not needed for W0: marketing registry, changelog, tutorials backlog (nothing a customer can see changed).
